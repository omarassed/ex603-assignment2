# EX 603 Assignment 2: Database Schema Implementation

## Overview
This repository contains the PostgreSQL relational database schema and constraint write-up for a Music Streaming & Publishing application.

## Repository Structure
* `/schema/schema.sql`: Complete DDL script ordered by foreign key dependencies.
* `/analysis/unit2.md`: Constraint rationale table, ON DELETE narratives, and CHECK constraint analysis.
* `/screenshots/`: Script execution and table creation verification screenshots.
